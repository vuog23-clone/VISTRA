`gpt-5-nano`, `gpt-6-luna` and `gpt-4.1-nano` sequence. Its status file records
progress and any model-access blockers. The report includes family checks,
latency, input/cached/output tokens and Standard-rate cost estimates.

Open [gpt-5-nano/REPORT.md](gpt-5-nano/REPORT.md) for the preserved first catalog run and the fresh retrieval supplement.
